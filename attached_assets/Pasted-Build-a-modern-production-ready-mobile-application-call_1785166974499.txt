Build a modern, production-ready mobile application called StatusSeller. The app enables businesses to turn their WhatsApp Status, Instagram Stories, Facebook Stories, TikTok posts, and other social media content into interactive shopping experiences.

The design should feel like a mix of Apple, Shopify, Stripe, WhatsApp, and Notion with a clean white interface, rounded corners (20–24px), subtle shadows, smooth animations, and premium typography. Every interaction should feel fast and polished.

Tech Stack
Use:

React Native with Expo for iOS and Android.
Supabase for Authentication, PostgreSQL database, Storage, and Edge Functions.
TypeScript throughout.
Zustand for state management.
React Navigation.
React Query (TanStack Query) for server state.
Tailwind CSS (NativeWind) for styling.
Stripe SDK and M-Pesa integration.
OpenAI or compatible LLM API for the AI assistant.
Firebase Cloud Messaging for push notifications.
Recharts or Victory Native for analytics.
Build the backend with Supabase and Edge Functions, exposing secure REST APIs.

The app should follow a clean architecture with reusable components, scalable folder structure, dark mode support, offline caching where possible, and smooth 60fps animations. Prioritize a premium user experience that feels like a world-class startup product similar to Shopify, Stripe, Linear, and Apple.

The code should be production-ready, modular, well-documented, and easy to extend with future features such as live shopping, affiliate marketing, influencer storefronts, and AI-powered recommendations.
